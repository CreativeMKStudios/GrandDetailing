# Grand Detailing

Static site for Grand Detailing, the car detailing service at 78 Stagsden Road, Bedford, MK43 8PU.

Facts, hours, reviews, and photos come from the public Google listing checked on 12 October 2026. Number plates in the photos are hidden. The Street View frame in Google’s photo count is not copied onto the site.

The live site is published with GitHub Pages from `main`.

https://creativemkstudios.github.io/GrandDetailing/

`site` and `base` in `astro.config.mjs` must stay in step with that address. The sitemap line in `public/robots.txt` uses the same origin.

```bash
npm install
npm run dev
npm run build
```
